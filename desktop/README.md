# Karaoke Punch — настольная версия

Караоке-студия с удалением вокала нейросетью. Всё считается на твоём
компьютере: ни звук, ни текст никуда не отправляются.

## Что умеет

Те же четыре шага, что и на сайте — песня, текст, редактор с дорожкой
и простукиванием, караоке, — плюс главное отличие настольной версии:

**🧠 Убрать вокал нейросетью** (шаг «Песня») — модель UVR-MDX-NET-Inst_HQ_3,
ровно та, которой считает UVR5. Качество несопоставимо с вычитанием
центрального канала: своя минусовка сходится с минусовкой настоящего UVR5
на 94 % по амплитуде.

Три способа получить минусовку остались на выбор:
1. Встроенное приглушение — мгновенно, качество среднее
2. Свой файл — если уже прогнал трек через UVR5 отдельно
3. Нейросеть прямо в приложении — лучшее качество без лишних программ

## Установка

- **macOS (Apple Silicon)**: `Karaoke Punch-1.0.0-arm64.dmg`
- **Windows (x64 и ARM)**: `Karaoke Punch Setup 1.0.0.exe`

Приложение подписано «для себя» (ad-hoc), но не заверено у Apple —
сертификат разработчика платный. Поэтому первый запуск требует одного
лишнего действия.

### macOS

1. Открой `.dmg` и перетащи приложение в «Программы».
2. Сними карантин, который вешает браузер на скачанные файлы — открой
   Терминал и выполни:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/Karaoke Punch.app"
   ```

3. Запускай как обычно.

Можно и без Терминала: попробуй открыть приложение, получи отказ, затем
зайди в Системные настройки → «Конфиденциальность и безопасность»,
пролистай вниз и нажми «Всё равно открыть». Способ через Терминал
надёжнее — он срабатывает всегда.

Совет «правый клик → Открыть» из старых инструкций в macOS 15 и новее
больше не работает: Apple убрала этот обход.

### Windows

SmartScreen покажет синее окно → «Подробнее» → «Выполнить в любом случае».

## Модель

При первом нажатии «Убрать вокал» приложение предложит скачать модель —
64 МБ, один раз. Дальше она лежит на диске и интернет больше не нужен:

- macOS: `~/Library/Application Support/Karaoke Punch/UVR-MDX-NET-Inst_HQ_3.onnx`
- Windows: `%APPDATA%\Karaoke Punch\UVR-MDX-NET-Inst_HQ_3.onnx`

До версии 1.9 здесь лежала htdemucs.onnx на 172 МБ. Она больше не нужна;
приложение один раз спросит, удалить ли её.

## Сколько ждать

Замерено на Apple M-серии, 8 потоков: **примерно 3,5 минуты на трек
в 3 минуты** (кусок 5,9 с считается около 5,2 с). Прежняя htdemucs шла
быстрее, около 0,9 длины трека, но оставляла в минусовке заметно
больше голоса.
На Windows скорость зависит от числа ядер. Прогресс и оставшееся время
показываются в окне, расчёт можно отменить.

## Разработка

```bash
npm install
npm start                  # запуск
npm run dist:mac           # сборка dmg для Apple Silicon
npm run dist:win           # сборка exe для Windows
```

Самопроверка без ручных кликов:

```bash
KARAOKE_SELFTEST=1 KARAOKE_E2E=1 npm start
```

Проверяет интерфейс, наличие модели и прогоняет реальное разделение на
25 секундах звука, после чего закрывается.

## Как это устроено

- `main.js` — окно, скачивание модели, отдача файлов через схему `app://`
  с заголовками изоляции (без них WebAssembly считает в один поток вместо восьми)
- `renderer/separator-worker.js` — разделение в фоновом потоке окна
- `renderer/dsp.js` — БПФ, оконное преобразование и обратное к нему;
  соглашения повторяют `torch.stft` с параметрами UVR (окно Ханна,
  center=True, normalized=False). У MDX-Net `n_fft` = 6144 — не степень
  двойки, поэтому к основанию 2 добавлена стадия по основанию 3
  (6144 = 2048 × 3)

Расчёт идёт на WebAssembly-версии ONNX. Нативный `onnxruntime-node` внутри
Electron падает с SIGTRAP при загрузке модели — проверено во всех трёх режимах
(utilityProcess, worker_threads, ELECTRON_RUN_AS_NODE), поэтому от него отказались.
Ускорение через CoreML тоже отпало: вся выдача становится нечисловой.

Модель: [UVR-MDX-NET-Inst_HQ_3](https://github.com/TRvlvr/model_repo) —
из набора моделей [Ultimate Vocal Remover](https://github.com/Anjok07/ultimatevocalremovergui) (MIT).
Её параметры (`n_fft` 6144, `dim_f` 3072, `dim_t` 8, `compensate` 1,022)
лежат в [model_data.json](https://raw.githubusercontent.com/TRvlvr/application_data/main/mdx_model_data/model_data.json)
под ключом `55657dd70583b0fedfba5f67df11d711` — это md5 последних
10 000 КБ файла модели, а не всего файла.
