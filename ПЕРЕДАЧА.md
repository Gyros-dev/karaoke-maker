# Передача работы

Записка следующему чату. Файл НЕ коммитится (он в исключении у всех
коммитов) — это рабочая записка, а не часть продукта.

Обновлено: 5 сентября 2026, после выпуска 1.24.4.

## Коротко о проекте

**Karaoke Punch** — караоке-студия. Живёт двумя телами:

* **сайт** (GitHub Pages, `index.html` + `app.js` + `style.css` + `i18n.js`)
  — без сборки, без зависимостей, политика безопасности `default-src 'self'`;
* **настольное приложение** (Electron, папка `desktop/`) — тот же интерфейс
  плюс две нейросети: удаление вокала и разметка текста.

Интерфейс переносится в приложение скриптом `npm run app:sync`
(`desktop/sync-renderer.js`): корневые файлы копируются в
`desktop/renderer/`, а настольные отличия (политика безопасности, блок
нейросетей, скрипты) дописываются там же. **Править надо корневые файлы**,
кроме `desktop/renderer/desktop.js`, `align.js`, `whisper-worker.js`,
`separator-worker.js`, `key-worker.js`, `pitchy.js`, `fft-indutny.js` —
эти живут только в приложении (в корне их нет, sync их не копирует).
Ещё в дереве лежит `desktop/style.css` — устаревший дубль сайтового,
он никуда не идёт; правильный — корневой `style.css`.

Весь код и все комментарии по-русски. Комментарий объясняет ПОЧЕМУ так,
а не что делает строка; во многих местах записана беда, которую правка
лечила, — это самое ценное, что там есть.

## Главное правило работы

**Самопроверка — не формальность, а способ не соврать.**

```bash
KARAOKE_SELFTEST=1 npm run app:start
```

Печатает `SELFTEST {…}` — семьдесят с лишним разделов, у каждого
`вНорме`. Гонять ПОСЛЕ КАЖДОЙ правки; выпускать только когда красных
ноль. Разделы живут в `desktop/main.js`, каждый обёрнут в
`__раздел('имя', …)` — обёртка снимает и возвращает состояние студии,
чтобы разделы не мешали друг другу.

Полезные ключи окружения:

| ключ | что делает |
|---|---|
| `KARAOKE_SELFTEST=1` | полный прогон |
| `--user-data-dir=<врем. папка>` | СВОЙ профиль: у человека приложение может быть запущено, и без своего профиля Electron молча выйдет (одна копия на профиль). Заодно так видно то, что видит новый человек |
| `KARAOKE_PROBE=<выражение>` или `=@файл` | выполнить выражение на странице, напечатать ответ и выйти — для быстрых вопросов на три числа |
| `KARAOKE_SHOT=путь.png` | снять живое окно (показывает окно на секунду) |
| `KARAOKE_SHOT_SCENE=финалкадр\|настройки\|сайт\|дуэт` | какую сцену готовить к снимку (сцены «финал» нет: финала на экране нет вовсе) |
| `KARAOKE_FOCUS=1` | проверить, доходит ли клавиатура до страницы (беда Windows) |


| `KARAOKE_E2E=быстро` | настоящее разделение на 25 секундах звука |
| `KARAOKE_SEP_EP=wasm\|webgpu` | заставить разделение считать процессором или видеокартой |
| `KARAOKE_ASR_E2E=путь` | полное распознавание файла |

## Проверка на Windows

Виртуалка Parallels видна с Мака, приложение гоняется прямо из папки
проекта. Готовый скрипт: `.wintest/run.bat` (папка в `.gitignore`).

```bash
prlctl list -a
prlctl exec "Windows 11" --current-user cmd.exe /c "\\Mac\Home\karaoke-maker\.wintest\run.bat"
```

Грабли, каждая стоила по получасу:

* **`--current-user` обязателен** — без него команда идёт от SYSTEM: нет
  профиля, нет рабочего стола, окно не показать;
* **скрипты только с CRLF** — `cmd` разбирает Unix-переводы строк в кашу;
* **из сетевой папки приложение ползёт** — копируйте в `%TEMP%` и
  прибивайте прежний экземпляр (он держит DLL);
* **видеокарты в виртуалке нет** — нужны `--disable-gpu --in-process-gpu`;
* **`>` в переменной окружения `cmd` рубит молча** — выражение для щупа
  передавайте файлом (`KARAOKE_PROBE=@путь`).

Чему научил первый прогон: из восьми красных семь были не про Windows.
На чистом профиле окно «Что нового» висело поверх студии весь прогон,
а редактор при открытом окне клавиш не слышит вовсе. Восьмой —
«дорожка вдвое ниже» — оказался не бедой: раздел мерил долю, которую
человек однажды оттянул мышью. **Мерить надо умолчание.**

## Как проверять на Windows

Виртуалка Parallels, приложение внутри неё. Команду гостю передавать
**отдельными доводами**, а НЕ одной строкой в кавычках:

```
prlctl exec "Windows 11" --current-user cmd.exe /c W:\karaoke-maker\.wintest\run.bat
```

Строка в кавычках (`"cmd.exe /c ..."`) принимается за имя программы:
такого файла нет, и prlctl молча выходит с кодом 2 — ни слова в stderr.
На этом я потерял семь выпусков, считая, что «виртуалка не отвечает».

Ещё две грабли того же рода:
* `timeout /t 2` в батнике падает с «Input redirection is not supported»,
  когда консольного ввода нет. Ждать через `ping -n 3 127.0.0.1 >nul`.
* метки и переменные в батниках — латиницей: кириллицу в именах
  cmd.exe не понимает даже с `chcp 65001`.

Батники лежат в `.wintest/`: `run.bat` — полная самопроверка (отчёт
в `out.txt`), `focus.bat` — проверка, доходит ли клавиатура до страницы
(отчёт в `focus.txt`). Перед прогоном пересобрать `npm run app:build:win`:
батник копирует `desktop/dist/win-arm64-unpacked`.

Файлы, которые пишет Windows через общую папку, на Маке принадлежат
root — своей же студии их потом не перезаписать (см. пункт про чужую
папку в самопроверке).

## Как выпускать

Полный порядок — в README, раздел «Как выпустить новую версию». Коротко:

1. «Что нового»: верхний список — ТОЛЬКО пункты нового выпуска, прежний
   верхний блок переезжает в `<details class="whatsnew-old">` под своим
   номером; `data-news-version` у `<html>` — на новый номер.
2. `node bump-version.js app X.Y.Z` и `node bump-version.js site X.Y.Z`.
3. Ссылки на установщики в `index.html` — четыре штуки, на новый тег.
4. Строка `notes` в `version.json` — **руками**, `bump-version` её не трогает.
5. `npm run app:sync`, самопроверка, `npm run app:build`.
6. Коммит, пуш.
7. Релиз на GitHub через API (токен из `git credential fill`, на диск
   не писать). **Приложить ПЯТЬ файлов**: три установщика, `latest.yml`
   и блок-карту. Без `latest.yml` автообновление не работает вовсе,
   а беда молчаливая.
8. `node check-release.js X.Y.Z` — девять галочек.

Загрузка большого файла у GitHub иногда висит на HTTP/2 и обрывается
по времени: повторять на `--http1.1`, огрызок от неудачной попытки
удалять (иначе имя занято).

## Что сделано за этот чат (1.16.0 → 1.24.4)

* **проект папкой** — песня, минусовка, фон и разметка в одном месте,
  Cmd+S / Cmd+O;
* **зеркало модели распознавания** — веса Whisper лежат у нас отдельным
  ПРЕДВАРИТЕЛЬНЫМ выпуском `models-whisper-small-1` (предварительным
  нарочно: иначе он стал бы «последним» и сломал автообновление);
* **разделение на видеокарте** — вчетверо быстрее, звук совпадает
  до четвёртого знака;
* **пропуск проигрышей** при разметке текста;
* **дуэты** — партии у строк, цвет, две строки горят разом;
* **своя громкость у отрезка оригинала**;
* **финал песни** — похвала и счёт, тремя ударами, и в видео;
* **определение тональности** по чистому вокалу (pitchy);
* **настройки караоке влезают в колонку** — ужат не текст, а воздух
  между рядами; раздел `настройкиВлезают` сторожит это дальше;
* **цвета дуэта** — пипетки в закладке «Цвет», цвет доходит до списка,
  сцены, кадра видео и проекта;
* **растяжимый список строк** — свой разделитель, как у остальных окон;
* **компактная панель параметров** — открыт ровно один раздел, тот,
  про который спросили щелчком (раздел `панельВыбранного`);
* **уборка высоты** — справка из-под дорожки ушла в руководство,
  строка про права в приложении — в значок у «Сохранить видео»;
* **логотип финала в полный рост** (`logo-full.png`), раздел
  `логотипФинала` мерит отношение точек к размеру в кадре;
* **сайт**: скачивание — главное действие, браузерная студия второй
  кнопкой с пометкой beta, кнопки «Открыть студию» в шапке больше нет;
* **`downloads.js`** (`npm run downloads`) — сколько раз скачали, по
  версиям и платформам; людей по этому числу не сосчитать, и скрипт
  говорит об этом сам;
* **финал ушёл со сцены в видео** — на сцене его нет вовсе, в кадре
  логотип гаснет, а не прыгает, похвала в одну строку, потолок счёта
  два миллиона (раздел `финал` мерит кадр и сторожит, чтобы окно
  не вернулось);
* **клавиатура возвращается странице сама** — `focusPage` зовётся
  на закрытии окна долгой работы и на смене шага (раздел
  `клавиатураВозвращается`);
* **понятный ответ на чужую папку** вместо `EACCES` (раздел
  `чужаяПапка`);
* **самопроверка гоняется на чистом профиле** — `npx electron desktop
  --user-data-dir=<временная папка>`: так видно то, что видит новый
  человек, и не мешает запущенному приложению;
* починки Windows: фокус, окно новостей в самопроверке.

## Чего человек не любит

* **Врущих признаков.** Самопроверка, которая зеленеет на сломанном или
  краснеет на здоровом, хуже её отсутствия. Если признак измеряет
  не то — чинить признак, а не подгонять порог.
* **Тихих отказов.** Молча не сохранилось, молча не скачалось, молча
  не применилось — это худшее, что может случиться.
* **Уверенного вранья.** «Проверено» говорить только про то, что
  действительно прогнал. Про Windows — только после прогона в виртуалке.
* Отвечать по-русски, коммиты и комментарии тоже.
